# Project Constitution

**Version:** 1.0
**Status:** APPROVED FOR BASELINE

## Core invariants

1. Offline-first is a product constraint.
2. Architectural decisions are explicit and traceable.
3. Unknown information remains `UNKNOWN`; it is never invented.
4. Performance claims require measurement on target hardware.
5. AI-generated proposals do not become decisions automatically.
6. Significant architectural changes require an ADR.
7. Requirements remain traceable to specifications and tests.
8. Security-sensitive material must never be committed.
9. Approved pedagogical requirements must not be silently weakened.
10. The governed repository is the project source of truth after baseline activation.
11. The LLM is not the sole authority for curriculum, mastery or progression.
12. Model choice is evidence-driven and replaceable unless explicitly locked by an approved ADR.
13. Context is task-routed to minimize token use and reduce contextual contamination.
