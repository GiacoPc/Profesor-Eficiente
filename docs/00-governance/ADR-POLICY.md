# ADR Policy

## When an ADR is required

Create an ADR for any significant change to:
- system boundaries;
- authority/invariants;
- LLM strategy;
- inference runtime;
- audio architecture;
- data persistence/security;
- Rust/Kotlin boundaries;
- performance-critical architecture;
- governance rules.

An ADR must state context, options, decision, consequences, evidence and affected artifacts.
