# Baseline Reconciliation v1.0

**Status:** APPROVED FOR BASELINE

## Rule

Conversation history is evidence for reconstruction, not the permanent source of truth. Distinguish requirements, approved directions, formal decisions, and unresolved proposals.

## Reconciled facts

- Android offline-first American-English pedagogical tutor.
- Learner starts at absolute zero and uses neutral Latin American Spanish.
- MCER/CEFR-governed curriculum is authoritative and locally available.
- Local RAG is governed; generated curriculum cannot silently override authoritative curriculum.
- Spoken interaction, natural prosody, correction, local learner-error memory, reinforcement and mastery gating are product requirements.
- Shadowing, chunking, Kaizen-oriented learning practices and related techniques are intended learning mechanisms.
- Rust is intended for performance-critical/core capabilities; Kotlin/Android remains the platform layer.
- The LLM is a capability component, not the sole authority for curriculum or progression.
- APE, SDT (Student Digital Twin) and FDM are established architectural directions.
- Model choice, inference runtime, speech stack, exact NPU use, memory strategy and performance targets remain pending evidence.

## Explicitly unresolved

No final LLM has been selected. Gemma candidates remain candidates.
No NPU compatibility or performance claim is approved without device evidence.
No STT/TTS/pronunciation/prosody implementation is selected.
No numerical latency, RAM, thermal or energy target is approved without measurement.

## Corrections

1. SDT terminology is standardized as Student Digital Twin.
2. GitHub is the remote repository host; governed repository artifacts plus evidence constitute the source of truth.
3. Conversation memory is not authoritative after repository baseline activation.
4. Architecture proposals require explicit ADR/spec approval before becoming decisions.

## First-baseline gate

The baseline is not complete until governance validation, repository policy, CI checks and the baseline tag are established.
