## Use

Populate this template from authoritative repository state. Do not reconstruct it from memory or a previous chat. If an item cannot be established, mark it `UNKNOWN` and apply the governing block rule.

## Economy rule

The bootstrap is intentionally compact. It is a pointer/decision context, not a replacement for source artifacts.
